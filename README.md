# Novel App by azrael.!!!

Ứng dụng viết tiểu thuyết & ghi chú cá nhân với phong cách thiết kế **Liquid Glass** mượt mà, tối giản.

## 🚀 Hướng dẫn Build APK tự động qua GitHub Actions:
1. Đẩy toàn bộ mã nguồn này lên kho chứa (Repository) của bạn trên GitHub.
2. Chuyển sang tab **Actions** trên GitHub.
3. Chờ từ 3-5 phút để máy chủ tự động biên dịch và đóng gói `.apk`.
4. Nhấn vào bản build hoàn tất và tải file **Novel-App-Release-APK** về điện thoại cài đặt!
